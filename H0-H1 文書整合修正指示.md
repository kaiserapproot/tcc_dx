## H0/H1-DOC-FIX — hardening 正本整合

`実装済み.md` と `次の実装.md` の H0/H1 正本だけを修正する。

production code / runtime / test behavior は変更しない。

### 1. N6 TLS execution mode

以下へ統一する。

```text
NORMAL_EXE=N6-01_ONLY
-RUN=DEFERRED_TO_N6_06
LIBTCC=DEFERRED_TO_N6_06
DLL=UNSUPPORTED_IN_N6
DLL_FAIL_CLOSED_FINALIZATION=N6_07
```

`-run` / libtcc を N6-01 の対応範囲として記載してはならない。

### 2. FAIL_CLOSED authority

`FAIL_CLOSED` は negative test によって次が証明済みの場合のみ使用する。

```text
DIAGNOSTIC=YES
COMPILE_FAILURE=YES
BAD_CODE_ACCEPTED=NO
TCC_CRASH=NO
```

証拠がないものは `UNVERIFIED` または `NOT_IMPLEMENTED_UNVERIFIED` とする。

少なくとも現時点では、

```text
CLASS_NEW_ARRAY_DELETE_ARRAY=UNVERIFIED
VIRTUAL_INHERITANCE=UNVERIFIED
```

として扱う。

### 3. Lifetime class の再結合禁止

以下の複合表記を authority に使用しない。

```text
L2/L3
L4/L5
```

H0 で固定した lifetime class を維持する。

```text
L0 = parser / expression temporary
L1 = function compilation lifetime
L2 = translation-unit compilation lifetime
L3 = TCCState lifetime
L4 = generated image / relocated code lifetime
L5 = process lifetime
L6 = thread lifetime
```

確定できない場合は、

```text
LIFETIME=UNPROVEN
CANDIDATES=L2,L3
```

のように表現する。

### 4. BUG-35 destructor authority

`__tcc_cpp_run_dtors` を current implementation の drain authority として使用しない。

current authority は、

```text
REGISTER_API=__tcc_cpp_register_dtor
REGISTRY_BACKEND=__tcc_cpp_register_exit
DRAIN_TRIGGER=tcc_run_dtors
DRAIN_FUNCTION=__run_on_exit
```

とする。

BUG-35 trace も同じ authority に統一する。

```text
function-local static
 -> destructor wrapper
 -> __tcc_cpp_register_dtor
 -> __tcc_cpp_register_exit
 -> runtime registry
 -> termination
 -> tcc_run_dtors()
 -> __run_on_exit()
 -> registered destructor invocation
```

`__tcc_cpp_run_dtors` は、

```text
STALE_CONTRACT_NAME
```

としてのみ記録する。

### 5. Audit status

H1 では状態を以下の4種類だけに統一する。

```text
SAFE
VIOLATION
UNPROVEN
DEFERRED_BY_SPEC
```

`UNKNOWN` は使用しない。

N6-01 TLS cleanup は、

```text
TLS_TCB_CLEANUP=DEFERRED_BY_SPEC_N6_04
TLS_ENTRY_CLEANUP=DEFERRED_BY_SPEC_N6_04
```

とする。
